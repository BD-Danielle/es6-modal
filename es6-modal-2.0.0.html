彈窗標題

一、 滾動鎖定機制說明

本彈窗使用了 CSS overscroll-behavior: contain;，當您將這段內容滾動到最底端或最頂端時，瀏覽器會自動切斷邊界傳輸，防止背景網頁產生滾動連鎖。


二、 { passive: false } 事件攔截機制

針對手機觸控滑動（Touchmove）或電腦滾輪（Wheel）事件，我們在 JS 監聽器中傳入 { passive: false }，確保背景遮罩層能完全攔截預設滾動行為。


三、 長文字測試段落 1

這是為了產生內部滾動條而設計的長內容段落。請嘗試在電腦上使用滾輪滾動，或在手機上記進行觸控滑動。


四、 長文字測試段落 2

繼續往下滑動，當滑動到最底端時，請特別觀察背景頁面，背景頁面完全不會移動或產生 iOS 橡皮筋彈跳現象。


五、 長文字測試段落 3

感謝您的測試！您現在已經成功到達內容的最底部。

Modal 防背景滾動展示頁面

請點擊下方按鈕開啟對話框。開啟後，無論在 Modal 內部滾動到底部，還是在背景遮罩上滑動手指，底層網頁均完全不會發生滾動連鎖（Scroll Chaining）！
